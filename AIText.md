You are my front‑end engineer.  
Your job is to build a multi‑page website using HTML, CSS and JavaScript, structured in multiple folders and files.  
Even though the website has multiple pages, it must behave like a single scrollable site with a sticky left‑side menu that highlights the active page/section as the user scrolls.

## ARCHITECTURE REQUIREMENTS
- Think deeply about the folder structure before writing any code.
- Create separate folders such as:
  /pages
  /components
  /styles
  /scripts
  /assets
- Each page should be its own HTML file inside /pages.
- The main index.html should import and assemble all pages into one scrollable experience.
- Use JavaScript to dynamically load each page into the main layout.
- The left menu must be sticky and always visible.
- The menu must highlight the current page/section based on scroll position.
- Use Motion.js for animations:
  npm install motion
  import { animate, scroll } from "motion"

## COMMITS
After every feature you implement, write a simulated commit message like:
COMMIT: "Added sticky sidebar navigation with active section highlighting"
