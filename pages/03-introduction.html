Introduction

What is this document?

Written by Lova

This guide is the single reference point for how Dyrenes Beskyttelse shows up on social media. It brings tone of voice, visual identity and platform‑specific rules together in one place, so that anyone writing, designing or scheduling a post — staff, volunteers, or an outside agency — can work from the same playbook.

What you'll find inside

  • An overview of every account we run and what each one is for
  • Guidance on which content types work best on which platform
  • A breakdown of each platform's audience
  • Our overall brand styleguide (fonts, colours, logo usage)
  • Detailed guidelines per platform: tone, sizes, safe zones, mockups
  • A content calendar structure and KPI framework for tracking results

How to use it

Treat this as a living reference, not a one‑time read. Skim the overview and styleguide once to understand the fundamentals, then return to the relevant platform chapter whenever you're planning or producing content for that channel.
